# SSEL project page

Static project website for **Hierarchical Embedding of DNA Barcode Taxonomy with Hyperbolic Entailment Cones**.

## Publish with GitHub Pages

1. Push these files to the repository's `main` branch, with `index.html` at the root.
2. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Open the published URL once GitHub Pages finishes deployment.

The site address is `https://zmgong.github.io/ssel_project_page/`. If the repository owner or name differs, update the canonical URL in `index.html` before publishing.

The GitHub and PDF buttons intentionally remain disabled until the research code and paper links are ready. The repository hosting this website should not be presented as the research implementation.

The Method overview and video illustrate a separate native-2D subset experiment, not a projection of the 768-dimensional model. The original research video is preserved separately; this web copy only corrects its outdated title.

The source repository is intentionally private. Publishing GitHub Pages from a private personal repository requires GitHub Pro. Keep the repository private; the intended project website is public.
